# Классификация изображений

## Техническое задание

Необходимо реализовать программное решение для автоматической
классификации изображения с использованием готовой модели машинного обучения.

На вход программы подаётся изображение.

Программа должна определить, какой объект наиболее вероятно изображён,
и вывести название класса и соответствующую оценку уверенности модели.

## Используемая модель

Для решения задачи классификации изображений используется модель
`MobileNetV2` с предобученными весами `ImageNet`.

MobileNetV2 — сверточная нейронная сеть, предназначенная для
классификации изображений. Архитектура была разработана с упором
на уменьшение количества вычислений и параметров при сохранении
хорошего качества классификации.

В данной работе используется готовая реализация MobileNetV2
из библиотеки Keras:

`MobileNetV2(weights="imagenet")`

Предобученные веса ImageNet позволяют использовать модель без
дополнительного обучения.

На вход модели подаётся RGB-изображение размером 224×224 пикселя.
На выходе модель формирует оценки для 1000 классов ImageNet.

Для запуска модели используется библиотека Keras на фреймворке TensorFlow.

## Преимущества Keras и TensorFlow

Для работы с моделью используется Keras на базе TensorFlow.

Основные преимущества:

- готовая реализация `MobileNetV2` в `keras.applications`
- возможность загрузить предобученные веса `ImageNet`
- простая подготовка изображений с помощью `load_img`, `img_to_array`
  и `preprocess_input`
- готовая функция `decode_predictions()` для перевода выхода модели
  в названия классов
- возможность выполнять inference локально без дополнительного обучения
- удобная интеграция с Python и NumPy

## Принцип работы модели

Модель `MobileNetV2` - сверточная нейронная сеть для классификации изображений. Она была разработана как облегченная архитектура, которая требует меньше вычеслений и параметров по сравнению с более тяжелыми моделями CNN.

Наша модель принимает изображение и определяет, к какому из 1000 классов ImageNet оно наиболее вероятно относится.

### 1. Подготовка изображения

Перед передачей в модель изображение необходимо привести к размеру "224*224" пикселя и приобразовать в числовой массив RGB-пикселей.

После этого применяется функция:

`preprocess_input()`

Она масштабирует значения писклеей в диапозон от '-1' до '1', который ожидает MobileNetV2.

В результате получаем:

изображение -> resize -> массив чисел -> нормализация

### 2. Извлечение признаков с помощью свёрток

MobileNetV2 анализирует изображение с помощью сверточных слоёв.

На первых слоях сеть выделяет простые признаки:

- границы объектов
- линии
- текстуры
- цветовые переходы

На более глубоких слоях эти признаки обьединяются в более сложные структуры, например в части обьектов или в целые обьекты.

Например, при распознавании собаки, модель постепенно может выделять сначала контуры, шерсть, форму головы и другие визуальные особенности.

### 3. Depthwise Separable Convolution

Одной из главных особенностей MobileNet является использование `depthwise separable convolution`.

В обычной свертке одновременно обрабатывается пространственная структура изображения и все какнлы признаков, что требует большого количества вычислений. А в MobileNet эти операции разделяются на две части:

1. `Depthwise convolution`: отдельный фильтр применяется к каждому
   каналу независимо.

2. `Pointwise convolution`: используется свёртка `1×1`, которая
   объединяет информацию между каналами.

То есть вместо одной дорогой операции выполняются две более легкие.

Это позволяет значительно уменьшить количество вычислений при сохранении способности модели извлекать полезные признаки.

### 4. Inverted Residual Block

Основным блоком MobileNetV2 является
`Inverted Residual Block`.

В обычных residual-архитектурах часто используется схема, где количество
каналов сначала уменьшается, а затем снова увеличивается. А в нашей модели используется обратный подход:

`узкое представление -> расширение -> обработка -> сжатие`

Сначала количество каналов увеличивается с помощью свёртки `1×1`.
Это позволяет модели сформировать более богатое пространство признаков.

После этого выполняется `depthwise convolution`, которая анализирует
пространственную структуру изображения.

Затем количество каналов снова уменьшается с помощью ещё одной
свёртки `1×1`.

Этот подход как раз и называется `inverted residual`, потому что ширококе предстваление находится внутри блока, а вход и выход блока остаются относительно узкими. Именно эта схема является одной из главных особенностей MobileNetV2. 

### 5. Linear Bottleneck

После расширения признаков модель снова сжимает их до меньшего количества каналов.

На этом узком выходном слое MobileNetV2 не использует дополнительную нелинейную функцию активации. 

Этот подход называется Linear Bottleneck. Его идея состоит в том, что применение сильной нелинейности в пространстве с небольшим количеством каналов может привести к потере части полезной информации. 

Поэтому узкий выход блока остается линейным, что помогает сохранить важные признаки изображения.

### 6. Residual connection

Если размеры входа и выхода блока совпадают, между ними может
использоваться residual connection. В таком случае вход блока добавляется к его выходу.

Такие связи помогают передавать информацию через глубокую сеть и
облегчают обучение модели.

В MobileNetV2 residual connection соединяет именно узкие представления,
что также уменьшает объём передаваемых данных.

### 7. Формирование итогового представления

После прохождения через последовательность inverted residual блоков
модель получает набор высокоуровневых признаков изображения.

На этом этапе признаки уже описывают не отдельные линии или текстуры,
а более сложные визуальные структуры объекта.

Далее признаки преобразуются в итоговый вектор, который используется
для классификации изображения.

### 8. Классификация

В последней части модели вычисляются оценки для 1000 классов ImageNet.

При использовании:

`MobileNetV2(weights="imagenet")`

модель уже содержит готовые веса, обученные на ImageNet.

Функция:

`decode_predictions()`

преобразует числовой выход модели в понятные названия классов и значения
`score`.

Например:

`sports_car — 87.4%`

Класс с наибольшим `score` выбирается как наиболее вероятный результат.

### Общая схема работы

`изображение`
→ `resize до 224×224`
→ `нормализация`
→ `сверточные слои`
→ `inverted residual blocks`
→ `depthwise separable convolution`
→ `извлечение высокоуровневых признаков`
→ `классификация по 1000 классам ImageNet`
→ `класс + score`

Основная причина выбора — хорошее соотношение качества классификации

поэтому подходит для локального inference и не требует мощного оборудования.

Такде модель уже обучена на датасете ImageNet и умеет классифицировать изображения по 1000 готовым классам, поэтому доп обучение в рамках данной работы не требуется.

Ещё одним преимуществом является наличие готовой реализации
`MobileNetV2` в библиотеке Keras:

`MobileNetV2(weights="imagenet")`

Это позволяет быстро загрузить предобученную модель и использовать её
для классификации изображений.

Итого, основные причины выбора:

## Структура датасета

Для предобучения модели `MobileNetV2` используются данные ImageNet.

ImageNet — крупный набор изображений, организованный по категориям объектов.
Полная база ImageNet содержит более 14 миллионов изображений и более
21 тысячи категорий (`synsets`).

Однако в данной работе используется модель с весами `ImageNet`,
предназначенными для классификации по подмножеству ImageNet,
которое применялось в соревновании ILSVRC 2012.

Это подмножество также часто называют `ImageNet-1K`, поскольку оно
содержит 1000 классов объектов.

### Классы данных

ImageNet организован не просто как список произвольных названий классов.
Категории связаны с системой WordNet.

Каждая категория называется `synset` — набор слов, обозначающих
одно понятие.

Например, отдельными классами могут быть:

- `banana`
- `sports_car`
- `golden_retriever`
- `tabby`
- `tiger_cat`
- `pug`
- `boxer`

Поэтому модель не имеет одного общего класса `dog` или `cat` для всех
изображений. Вместо этого в ImageNet существуют более конкретные классы,
например отдельные породы собак или разновидности кошек.

Именно поэтому при тестировании модели ожидаемый класс должен совпадать
с конкретным классом ImageNet, а не только с общей категорией объекта.

### Разделение датасета

Подмножество ImageNet, используемое для ILSVRC 2012, содержит
1000 классов и разделено на три основные части:

#### Training set

Обучающая выборка содержит: `1 281 167 изображений`

Она используется для обучения параметров нейронной сети.

Количество обучающих изображений различается для разных классов
и составляет примерно от 732 до 1300 изображений на один класс.

#### Validation set

Валидационная выборка содержит:

`50 000 изображений`

Для каждого из 1000 классов используется по 50 изображений. Эта часть данных применяется для оценки качества модели в процессе
разработки и сравнения различных моделей.

#### Test set

Тестовая выборка содержит:

`100 000 изображений`

Для каждого класса приходится примерно по 100 изображений. При проведении соревнования ILSVRC правильные метки тестовых изображений
не предоставлялись участникам. Модель должна была самостоятельно
предсказать классы, после чего результаты оценивались организаторами.

### Структура одного примера

Основной объект датасета — изображение и связанная с ним метка класса.

Упрощённо один пример можно представить следующим образом:

{
    "image": "изображение в формате JPEG",
    "label": "идентификатор класса ImageNet",
    "class_name": "название объекта"
}

Например:

{
    "image": "...JPEG",
    "label": "...",
    "class_name": "golden_retriever"
}

Каждому из 1000 классов соответствует собственный идентификатор
и человекочитаемое название.

### Использование классов в MobileNetV2

При создании модели:

`MobileNetV2(weights="imagenet")`

загружаются веса, уже обученные на ImageNet.

При стандартной конфигурации выходной слой модели содержит
1000 выходных значений — по одному для каждого класса ImageNet.

После выполнения:

`model.predict(image_array)`

модель возвращает оценки для всех 1000 классов.

Функция:

`decode_predictions(predictions)`

сопоставляет числовые выходы модели с идентификаторами и названиями
классов ImageNet и возвращает наиболее вероятные варианты.

Например:

`golden_retriever — 91.25%`

### Особенности изображений

Исходные изображения ImageNet имеют различные размеры и соотношения сторон.

Модель MobileNetV2 при использовании стандартной конфигурации принимает
входное RGB-изображение размером `224×224` пикселя.

Поэтому перед передачей изображения в модель в нашей реализации
оно приводится к требуемому размеру:

`target_size=(224, 224)`

После этого изображение преобразуется в массив RGB-пикселей и
нормализуется функцией `preprocess_input()`.


Таким образом, используемый вариант ImageNet представляет собой
крупный набор изображений из 1000 классов объектов.

Для обучения используются более 1,28 млн изображений, а отдельные
validation и test выборки позволяют оценивать качество классификации.

Модель MobileNetV2 уже обучена на этих данных, поэтому в данной работе
не требуется самостоятельно обучать сеть — достаточно загрузить
готовые веса `ImageNet` и использовать их для inference.

## Метрики качества и эффективности модели

Для оценки MobileNetV2 используются как метрики качества классификации,
так и характеристики вычислительной эффективности.

### Качество классификации

Для MobileNetV2 с весами ImageNet опубликованы следующие результаты:

- Top-1 Accuracy — 71.3%
- Top-5 Accuracy — 90.1%.

Top-1 Accuracy показывает, как часто правильный класс находится
на первом месте среди предсказаний модели.

Top-5 Accuracy показывает, как часто правильный класс входит
в пять наиболее вероятных вариантов.

### Размер и количество параметров

MobileNetV2 имеет:

- размер модели — около 14 MB
- количество параметров — около 3.5 млн
- глубина модели — 105 слоёв.

Небольшое количество параметров является одной из причин высокой
вычислительной эффективности MobileNetV2 по сравнению с более тяжёлыми
сверточными архитектурами.

### Скорость inference

В официальных измерениях Keras среднее время одного inference step
для MobileNetV2 составляет:

- CPU — около 25.9 ms
- GPU — около 3.8 ms.

Эти значения получены в тестовой среде Keras и зависят от оборудования,
размера batch и условий запуска, поэтому их нельзя напрямую сравнивать
с результатами локального тестирования.

### Результаты собственной проверки

На собственном тестовом наборе были получены следующие результаты:

- проверено изображений — 11
- правильно классифицировано — 10 из 11
- Accuracy — 90.91%
- среднее время inference — 0.068 секунды на одно изображение.

Собственная Accuracy рассчитана на небольшом тестовом наборе и не
является заменой официальным метрикам ImageNet.

## Особенности реализации алгоритма и его эффективность

Для классификации изображений используется готовая модель
`MobileNetV2` с весами `ImageNet`.

Алгоритм работы программы:

1. Пользователь указывает путь к изображению.
2. Изображение загружается и приводится к размеру `224×224` пикселя.
3. Изображение преобразуется в числовой массив значений RGB-пикселей.
4. С помощью `preprocess_input()` значения пикселей нормализуются
   в диапазон от `-1` до `1`.
5. Подготовленное изображение передаётся в `MobileNetV2`.
6. Модель вычисляет оценки для 1000 классов ImageNet.
7. Функция `decode_predictions()` преобразует результат
   в названия классов и значения `score`.
8. Пользователю выводится наиболее вероятный класс и Top-5 вариантов.

Основная классификация выполняется с помощью:

`model.predict(image_array)`

Модель загружается один раз при запуске программы и далее может
использоваться для обработки изображений без повторной загрузки весов.

Для проверки реализации был создан отдельный файл `evaluate.py`,
который автоматически обрабатывает тестовые изображения,
сравнивает предсказанный класс с ожидаемым и рассчитывает Accuracy
и среднее время inference.

На собственном тестовом наборе из 11 изображений были получены результаты:

- правильно классифицировано — 10 из 11
- Accuracy — 90.91%
- среднее время inference — 0.068 секунды.

MobileNetV2 имеет около 3.5 млн параметров и размер около 14 MB,
что делает её достаточно компактной и подходящей для локального inference.

Дополнительное обучение модели в данной работе не требуется,
так как используются готовые веса ImageNet.

## Итог

В рамках работы было реализовано программное решение для классификации
изображений с использованием готовой модели `MobileNetV2`.

Модель работает на базе Keras и TensorFlow и использует предобученные
веса `ImageNet`, поэтому дополнительное обучение не требуется.

Программа принимает изображение, подготавливает его к нужному формату,
выполняет inference и выводит наиболее вероятный класс объекта,
а также несколько дополнительных вариантов с соответствующими значениями
`score`.

MobileNetV2 сочетает сравнительно высокое качество классификации
с небольшим размером модели и количеством параметров, поэтому подходит
для локального использования и задач, где важна вычислительная эффективность.

Основным ограничением является то, что модель предсказывает только
классы, представленные в ImageNet-1K, поэтому она не предназначена
для распознавания произвольных пользовательских категорий без
дополнительного обучения.
