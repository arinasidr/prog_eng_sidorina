# Распознавание действий на видео

## Техническое задание

Необходимо реализовать программное решение для автоматического
распознавания действия на видео с использованием готовой модели
машинного обучения.

На вход программы подаётся видеофайл.

Программа должна проанализировать последовательность кадров,
определить наиболее вероятное действие и вывести название класса
и соответствующую оценку уверенности модели.

## Используемая модель

Для решения задачи распознавания действий на видео используется модель
`R3D-18`.

R3D-18 — это 18-слойная трёхмерная сверточная нейронная сеть
(3D Convolutional Neural Network), предназначенная для классификации видео.

В отличие от обычных CNN для изображений, R3D-18 анализирует не только
пространственную информацию внутри отдельных кадров, но и изменения
между кадрами во времени.

В данной работе используется готовая реализация модели из библиотеки
`torchvision`:

`r3d_18(weights=R3D_18_Weights.KINETICS400_V1)`

Используемые веса `KINETICS400_V1` были обучены на датасете Kinetics-400,
который содержит 400 классов различных действий.

Модель получает последовательность кадров видео и возвращает оценки
для 400 возможных классов действий.

Для запуска модели используется фреймворк PyTorch и библиотека torchvision.


## Преимущества PyTorch и torchvision

Для работы с моделью используются фреймворк PyTorch и библиотека torchvision.

Основные преимущества:

- готовая реализация модели `R3D-18`
- возможность загрузить предобученные веса `KINETICS400_V1`
- готовые преобразования входного видео через `weights.transforms()`
- удобная работа с многомерными тензорами видео
- простой перевод модели в режим inference с помощью `model.eval()`
- возможность отключить вычисление градиентов через `torch.inference_mode()`,
  что уменьшает лишние вычисления
- локальный запуск модели без обращения к внешнему API
- удобный доступ к названиям классов через `weights.meta["categories"]`

## Принцип работы модели

Модель `R3D-18` предназначена для классификации действий на видео.

Ее основное отличие от обычной модели для изображений заключается в том, что она анализирует не один кадр, а сразу последовательность кадров. Это позволяет модели учитывать не только, то что статично находится на изображении, но и то, как обьекты изменяются и двигаются во времени.

### 1. Видео представляется как последовательность кадров

Видео можно представить как набор изображений, идущих друг за другом. В нашей реализации из видео выбирается последовательность из 16 кадров, каждый из которых содержит информацию о:
- высоте изображения
- ширине изображения
- трех цветовых каналах (RGB)

После подготовки кадры обьединяются в один многомерный тензор, который и передается модели

Упрощенно его можно представить как: цветовые каналы * время * высота * ширина

Таким образом, модель получает сразу небольшой фрагмент видео, а не отдельную фотографию/изображение.

### 2. 3D-свёртки

R3D-18 является трёхмерной сверточной нейронной сетью. 

В обычной CNN для изображений свёртка анализирует данные только
по двум направлениям: ширина * высота. То есть модель изучает пространственные признаки изображения: границы, формы, текстуры и части обьектов.

В нашей модели же используется 3D-свертка, которая работает сразу по 3 направлениям: время * высота * ширина. Поэтому фильтр анализирует не только участок одного кадра, но и тот же самый участок на соседних кадрах. Именно благодаря этому модель может замечать движение/действие

### 3. Извлечение признаков

Последовательность кадров проходит через несколько сверточных слоев. На начальных слоях модель выделяет относительно простые признаки:
- границы обьектов
- текстуры
- формы
- небольшие движения между сосденими кадрами

На более глубоких слоях эти признаки обьединяются и модель начинает распознавать более сложные элементы:
- людей
- положение частей тела (рук, ног и тд)
- предметы в кадре
- направление движения
- изменение положения обьектов во времени

В результате модель формирует общее представление о том, что происходит в данном фрагменте видео

### 4. Архитектура ResNet-18

Название `R3D-18` можно условно разделить на две части:

- `R3D` — Residual 3D Network, то есть сеть с трёхмерными свёртками
- `18` — глубина архитектуры, основанной на ResNet-18

Модель использует residual-блоки — блоки с дополнительными
прямыми связями между слоями.

### 5. Residual connections

В глубоких нейронных сетях информация проходит через большое количество
слоёв и постепенно преобразуется. В ResNet используются дополнительные связи, позволяющие передавать
исходную информацию через блок напрямую.

Упрощённо:

`вход → несколько слоёв → результат`

и одновременно:

`вход ─────────────────→ + результат`

То есть результат обработки объединяется с исходным входом блока.

Такие связи помогают глубоким моделям сохранять полезную информацию
и упрощают их обучение.

### 6. Получение общего представления видео

После прохождения через последовательность 3D-свёрток и residual-блоков
модель получает набор признаков, характеризующих весь анализируемый
фрагмент видео.

На этом этапе модель уже работает не с исходными пикселями,
а с признаками высокого уровня, описывающими объекты и движение.

Далее эти признаки объединяются в единое представление видео,
которое передаётся классификатору.

### 7. Классификация действия

Используемая модель обучена на датасете `Kinetics-400`. Поэтому на выходе R3D-18 формирует оценки для 400 возможных действий.

Например:

- `playing guitar`
- `drinking`
- `playing basketball`
- `brushing teeth`
- `clapping`
- и другие.

В нашей реализации результат модели преобразуется с помощью `softmax`,
после чего выбираются пять классов с наибольшими значениями.

Например:

`strumming guitar — 84.68%`

`playing guitar — 14.56%`

Это позволяет увидеть не только самый вероятный класс,
но и другие действия, которые модель считает похожими.

### Общая схема работы

`видеофайл`
→ `последовательность кадров`
→ `подготовка кадров`
→ `3D-свёртки`
→ `анализ изображения и движения во времени`
→ `Residual-блоки`
→ `формирование признаков видео`
→ `классификатор`
→ `оценки 400 классов Kinetics-400`
→ `Top-5 действий`

## Причины выбора модели

Для решения задачи была выбрана модель `R3D-18` с предобученными весами `KINETICS400_V1`.

Основная причина выбора — модель специально предназначена для классификации действий на видео.

R3D-18 использует 3D-свёртки, поэтому анализирует не только содержимое отдельных кадров, но и изменения между ними во времени. Это позволяет распознавать именно действия, а не только объекты в кадре.

Также модель уже обучена на датасете Kinetics-400 и может классифицировать видео по 400 готовым классам действий.

Дополнительными преимуществами являются:

- готовая реализация в библиотеке `torchvision`
- наличие предобученных весов `KINETICS400_V1`
- отсутствие необходимости самостоятельно обучать модель
- возможность локального inference
- готовые преобразования входного видео через `weights.transforms()`
- получение названий классов через `weights.meta["categories"]`
- относительно простая интеграция с PyTorch

Таким образом, R3D-18 подходит для данной работы, поскольку позволяет реализовать классификацию действий на видео с использованием готовой предобученной модели без собственного обучения.

## Структура датасета

Для обучения модели `R3D-18` использовался датасет `Kinetics-400`.

Kinetics-400 — это датасет для распознавания действий человека на видео. Он содержит 400 различных классов действий. Для каждого класса собрано как минимум несколько сотен коротких видеороликов. Каждый видеоклип длится примерно 10 секунд и содержит одно основное действие.

Примеры классов:
- `playing guitar`
- `strumming guitar`
- `drinking`
- `drinking beer`
- `playing basketball`
- `brushing teeth`
- `clapping`
- `push up`
- `playing violin`
- и другие.

Датасет содержит действия разных типов:

- действия человека с предметами
- спортивные действия
- музыкальные действия
- бытовые действия
- взаимодействия между людьми

Видео были собраны из YouTube и содержат реальные сцены с различным освещением, фоном, положением камеры и внешним видом людей.

### Разделение данных

Kinetics-400 разделён на несколько частей:

- `train` — данные для обучения модели
- `validation` — данные для проверки качества во время разработки
- `test` — данные для финальной оценки

В различных публикациях для Kinetics-400 обычно указывается около 240 тысяч обучающих видео и около 20 тысяч validation-видео.Каждое видео связано с одним классом действия.

### Структура одного примера

Один пример датасета включает:

- последовательность видеокадров
- аудиодорожку
- числовую метку класса

В torchvision один элемент датасета возвращается в виде:

`video, audio, label`

где:

- `video` — последовательность кадров
- `audio` — аудиоданные
- `label` — номер класса действия

### Особенность классов Kinetics-400

Классы Kinetics-400 могут быть близкими по смыслу.

Например, отдельно существуют:

`playing guitar`

`strumming guitar`

`tapping guitar`

Поэтому одно видео может визуально быть похоже сразу на несколько разных классов.

Кроме того, в Kinetics-400 нет класса для любого возможного действия.
Если подходящего класса нет, модель всё равно должна выбрать один
из доступных 400 вариантов.

Это является одной из причин, почему для произвольных пользовательских
видео результат может быть неоднозначным.

Таким образом, Kinetics-400 представляет собой большой датасет коротких
видеороликов с 400 классами человеческих действий.

Модель R3D-18 была обучена на этих данных и поэтому при классификации
может выбирать только один из классов Kinetics-400.

## Метрики качества и эффективности модели

Для оценки R3D-18 используются метрики качества классификации
и характеристики вычислительной эффективности.

### Качество классификации

Для модели `R3D-18` с весами `KINETICS400_V1`
на датасете Kinetics-400 опубликованы следующие результаты:

- Top-1 Accuracy — 63.2%
- Top-5 Accuracy — 83.479%.

Top-1 Accuracy показывает, как часто правильный класс действия
оказывается на первом месте среди всех предсказаний модели.

Top-5 Accuracy показывает, как часто правильный класс входит
в пять наиболее вероятных вариантов.

Официальная оценка выполнялась на уровне целого видео:
использовались клипы длиной 16 кадров, частота 15 кадров/с
и 5 клипов на одно видео.

### Размер и количество параметров

R3D-18 имеет:

- количество параметров — 33 371 472
- размер файла весов — около 127.4 MB
- вычислительная сложность — около 40.7 GFLOPS.

Модель значительно тяжелее MobileNetV2, что связано с обработкой
не одного изображения, а последовательности видеокадров и использованием
3D-свёрток.

### Результаты собственной проверки

Для проверки реализации использовались несколько произвольных
видеороликов с различными действиями.

Автоматический расчёт Accuracy на собственном наборе не выполнялся,
поскольку модель работает только с фиксированными классами Kinetics-400,
а произвольное видео может соответствовать нескольким близким классам
или не иметь точного соответствия среди 400 категорий.

Вместо этого анализировались Top-5 предсказаний модели.

Примеры результатов:

`playing_guitar1.mp4`

- `strumming guitar` — 84.68%
- `playing guitar` — 14.56%

`drink.mp4`

- `drinking beer` — 20.58%
- `drinking` — 14.94%

`walk.mp4`

- `disc golfing` — 36.81%
- `lunge` — 15.55%.

Результаты показывают, что качество предсказания зависит
от соответствия действия классам Kinetics-400 и от выбранного
фрагмента видеозаписи.

Таким образом, официальная Top-1 Accuracy R3D-18 на Kinetics-400
составляет 63.2%, а Top-5 Accuracy — 83.479%.

При работе с пользовательскими видео анализ Top-5 особенно полезен,
поскольку несколько классов Kinetics-400 могут описывать визуально
похожие действия.

## Особенности реализации алгоритма и его эффективность

Для обработки видео используется библиотека OpenCV, а классификация
выполняется моделью `R3D-18` из `torchvision`.

Алгоритм работы программы:

1. Пользователь указывает путь к видеофайлу.
2. Видео открывается с помощью `OpenCV`.
3. Определяется общее количество кадров.
4. Из середины видео выбирается последовательность из 16 кадров.
5. Каждый кадр преобразуется из формата BGR в RGB.
6. Кадры переводятся в тензоры PyTorch и объединяются в один видеотензор.
7. С помощью `weights.transforms()` выполняется подготовка данных:
   изменение размера, обрезка изображения и нормализация.
8. Подготовленный видеоклип передаётся в модель `R3D-18`.
9. Результат модели преобразуется с помощью `softmax`.
10. Выбираются пять классов с наибольшими значениями вероятности.

Для inference используется:

`torch.inference_mode()`

Этот режим отключает вычисление градиентов, которые не нужны при
классификации готовой моделью, и уменьшает лишние вычисления.

Модель переводится в режим:

`model.eval()`

Это необходимо для корректной работы слоёв сети во время inference.

### Работа с видеоклипом

R3D-18 получает на вход не целое видео, а короткую последовательность кадров.

В данной реализации используется 16 последовательных кадров,
выбранных из середины видео.

Такой подход позволяет модели анализировать движение между соседними
кадрами и при этом не обрабатывать весь видеоролик целиком.

Если видео содержит меньше 16 доступных кадров, последний успешно
прочитанный кадр дублируется до необходимой длины.

### Эффективность реализации

Использование только 16 кадров уменьшает объём вычислений по сравнению
с обработкой всего видео.

Предобученная модель загружается один раз при запуске программы,
после чего используется для выполнения inference без дополнительного
обучения.

При этом R3D-18 остаётся достаточно вычислительно тяжёлой моделью:

- около 33.4 млн параметров
- размер весов около 127.4 MB
- вычислительная сложность около 40.7 GFLOPS.

Это связано с использованием 3D-свёрток, которые одновременно
обрабатывают пространственные и временные признаки видеоклипа.

### Ограничения реализации

Результат классификации зависит от выбранного фрагмента видео.

Если основное действие происходит не в середине ролика, выбранные
16 кадров могут не содержать достаточной информации для правильного
распознавания.

Кроме того, модель может выбирать только из 400 классов Kinetics-400.
Поэтому произвольное пользовательское видео не всегда имеет точное
соответствие одному из доступных классов.

Из-за этого в программе выводится Top-5 предсказаний, что позволяет
увидеть несколько наиболее вероятных вариантов действия.

## Итог

В рамках работы было реализовано программное решение для распознавания
действий на видео с использованием готовой модели `R3D-18`.

Модель работает на базе PyTorch и torchvision и использует
предобученные веса `KINETICS400_V1`, поэтому дополнительное обучение
не требуется.

Программа получает видеофайл, выбирает последовательность из 16 кадров,
подготавливает их к необходимому формату и передаёт в модель.

R3D-18 использует 3D-свёртки, благодаря чему анализирует одновременно
пространственную информацию внутри кадров и изменения между кадрами
во времени.

На выходе модель формирует оценки для 400 классов Kinetics-400.
В программе выводятся пять наиболее вероятных действий.

Ручная проверка показала, что модель способна корректно определять
действия, соответствующие классам Kinetics-400. Например, для видео
с игрой на гитаре были получены классы `strumming guitar`
и `playing guitar`, а для видео с питьём — `drinking beer`
и `drinking`.

Основными ограничениями решения являются фиксированный набор из
400 классов и зависимость результата от выбранного фрагмента видео.
Если нужное действие отсутствует среди классов Kinetics-400 или плохо
представлено в выбранных кадрах, модель может вернуть похожее,
но неправильное действие.

Таким образом, R3D-18 позволяет реализовать локальную классификацию
действий на видео без самостоятельного обучения модели.
